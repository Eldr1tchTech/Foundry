# Foundry
A C base layer, has the basic tools needed for most if not any project you will write in C.

## Limitations
- Linux for async_io (IO uring)
- clang/gcc
- Wayland and Vulkan for Kiln

## Features
- Build System
- Hashmap
- Dynamic Array
- Async IO
- Protothreads
- Allocators
  - GPA
  - Pool
  - Arena
- Strings (sds)
- Linked List
- Test Suite
